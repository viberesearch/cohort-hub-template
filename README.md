# cohort-hub-template

Шаблон хаба программы — репозитория организаторов многомесячной проектной
программы, в которой учатся несколько команд. В хабе лежит всё, что
записывается на модулях: расписание, транскрипты, материалы, итоги пленарных
разборов. Участники хаб читают; команды сдают материалы через issue.

*English: a template for the organizers' hub of a cohort programme: schedule,
verbatim transcripts, materials and plenary outcomes of every module. Participants
read it; teams submit via issues. Agent rules are in `AGENTS.md` and `rules/`.*

Командам — шаблон рабочего репозитория:
[triad-workspace-template](https://github.com/viberesearch/triad-workspace-template).
Схемы, как связаны хаб и репозитории команд:
[HOW_IT_WORKS.md](https://github.com/viberesearch/triad-workspace-template/blob/main/HOW_IT_WORKS.md).

## Как развернуть (организаторам)

1. Создать **приватный** репозиторий из этого шаблона в организации на GitHub
   («Use this template» или
   `gh repo create <org>/<name> --private --template viberesearch/cohort-hub-template`).
   Шаблон публичный и пустой; живой хаб с записями публичным делать не нужно:
   в записях обсуждаются проекты команд.
2. Дать участникам роль **Read** (роли в организации доступны и на бесплатном
   плане). С ролью Read участник читает хаб и открывает issue.
3. Заполнить `schedule.md`, `rules/local/hub.yaml` и `rules/for_teams.yaml`.
4. Прочитать `RECORDING_PROTOCOL.md` и объявить его участникам до первого
   модуля.

Модель организатора (Claude Code, Codex и т. п.) делает всё это по промпту:

```text
Работай по AGENTS.md. Задача: разверни хаб программы из этого шаблона и выдай доступ участникам.
```

## Что внутри

Хаб устроен по принципу «сначала атомы»: всё сырое (транскрипты лекций и
разборов, материалы, сдачи команд) хранится в исходном виде и служит источником
для любого анализа, структурирования и отображения.

| Путь | Что это |
|---|---|
| `OVERVIEW_ru.html` | Обзор для организаторов на одной странице: схемы, что это даёт, что нужно сделать. Открывается без интернета |
| `AGENTS.md`, `rules/` | Правила для моделей организаторов и участников |
| `rules/for_teams.yaml` | Правила программы для моделей команд: сроки, форматы, сдача. Команды получают изменения при следующем `pull` |
| `RECORDING_PROTOCOL.md` | Как записываем, как убрать фрагмент, кому принадлежат данные |
| `schedule.md` | Расписание модулей и сверок |
| `atoms/NN_<место>_<ГГГГ-ММ>/` | Сырьё модуля: `manifest.yaml`, `transcripts/`, `materials/`. После публикации не меняется |
| `atoms/submissions/<команда>/` | Сдачи команд в исходном виде |
| `derived/` | Всё, что построено из атомов: конспекты, итоги разборов, указатели, страницы команд. У каждого файла — ссылки на атомы и способ получения |
| `scripts/check.sh` | Проверки: секреты, неизменность атомов, массовые удаления |
