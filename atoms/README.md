# atoms — сырые данные

Всё, что записано и получено на программе, в исходном виде: транскрипты,
материалы, сдачи команд. Это источник для любого дальнейшего анализа,
структурирования и отображения (`../derived/`).

После публикации атом не меняется. Единственное исключение — изъятие фрагмента по
запросу участника (`RECORDING_PROTOCOL.md`), с записью в шапке файла и новой
контрольной суммой.
