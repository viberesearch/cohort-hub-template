# derived — всё, что построено из атомов

Конспекты, итоги пленарных разборов, указатели, страницы команд, карты,
отображения. Каждый файл указывает, из каких атомов и каким способом получен
(`derived_from`, `method`), поэтому его можно пересобрать или удалить без потери
данных. Факт в производном файле без ссылки на атом не принимается.
