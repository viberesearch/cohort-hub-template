Общая память программы на GitHub

Всё, что записывается на модулях, хранится как сырьё («атомы») и служит источником для любого анализа. Команды работают со своими материалами и с этим сырьём через свои ИИ-модели — по одним правилам.

Что это даёт

организаторам
  • одна база сырья по всем модулям, которая не портится со временем;
  • любой анализ, конспект или отображение пересобирается из атомов;
  • правила для ИИ-моделей всех команд — в одном файле хаба, изменения доходят до команд при следующем обновлении;
  • сдачи команд — через формы, в едином формате.
участникам
  • данные принадлежат участникам: весь хаб можно скачать себе;
  • знать GitHub не нужно — модель (Claude Code, Codex, Cursor) настраивает всё по готовому промпту;
  • каждая модель работает по одним правилам, поэтому команде легко работать вместе.
приватность
  • хаб и репозитории команд приватные;
  • команды не видят работу друг друга, пока сами её не сдали;
  • публичны только пустые шаблоны.
